# 🌊 Ocean Protector — Academic Clone Project

An educational web project based on **Ocean Protector**, an interactive game designed to help users learn about **ocean acidification and its impact on marine ecosystems**.

> **Attribution & Disclaimer**  
> This repository contains a **clone of the existing Ocean Protector educational project** developed by **Outreach Games**. I worked with this project as a **first-year college academic/learning exercise** to understand web development, project structure, interactive educational applications, and deployment.
>
> I do **not claim ownership** of the original source code, game assets, educational content, branding, or intellectual property belonging to the original creators.

## 📌 About the Project

Ocean Protector is an educational interactive experience focused on **ocean acidification** and its effects on marine life.

This repository was created during my **first year of college** as a learning project. The project helped me gain practical exposure to:

-  HTML and web page structure
-  CSS styling and customization
-  JavaScript-based interactions
-  Organizing web assets and project files
-  Integrating an interactive educational game
-  Deploying a static website using GitHub Pages

---

##  Project Features

- Educational content about ocean acidification
- Interactive web interface
- Ocean pH visualization
- Marine ecosystem information
- Interactive game component
- Light/Dark/Auto theme support
- Educational resources for further learning

## 🚀 Running the Project

### Option 1 — Open Locally

Clone the repository:

```bash
git clone https://github.com/RAMATHATCHANA/Ocean_Protector.git
```

Navigate into the project:

```bash
cd Ocean_Protector
```

Open:

```text
OceanProtector/main.html
```

in a web browser.

### Option 2 — GitHub Pages

The project can also be accessed through GitHub Pages after enabling deployment from the `main` branch.
